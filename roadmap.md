## Этап 2: озвучиватель манги (сделано 2026-09-26)

Фича «Озвучиватель манги» (`ChatInput` → `MangaVoiceModal` → `manga-analyze` + `dialog-tts`) дошла
до состояния «работает на реальных сканах». Что было сломано и как починено:

- [x] **Озвучка падала на «человеческом» транскрипте.** `dialog-tts` разбирает только строки
  `^Speaker N: …`, а модель и пользователь пишут «Рассказчик: …», «Аки: …», «— Привет» —
  сервер отвечал 400 «Не найдено реплик». Добавлена нормализация на клиенте
  (`src/lib/mangaTranscript.ts`): имена получают стабильные номера, реплики без автора
  остаются за предыдущим персонажем, результат гарантированно проходит серверный шаблон
- [x] **Лимиты озвучки проверяются до запроса** (8 голосов, 40 реплик для 3+ голосов) —
  вместо 400 от сервера показываем причину
- [x] **Батч из 5 сканов не влезал в запрос.** Страницы уходят inline-base64 одним JSON:
  5 × 10 МБ → десятки мегабайт. Добавлено сжатие на клиенте (`src/lib/mangaPages.ts`):
  уменьшение до 1600 px + JPEG с понижением качества до лимита 1.5 МБ, с фолбэком
  на исходник, если canvas/декодер недоступны
- [x] **`manga-analyze` падал на не-идеальном JSON модели** (`JSON.parse` по сырому ответу):
  разбор вынесен в `supabase/functions/manga-analyze/parse.ts` — заборы ```json, текст вокруг
  объекта, транскрипт-массив, обрезка полей; добавлены таймаут 120 с и понятные ошибки
  для 429/402/413/5xx
- [x] **При переоткрытии модалки все озвученные страницы стартовали одновременно**
  (`<audio autoPlay>`): у `AudioPlayer` появился проп `autoPlay` и пауза по `STOP_SPEECH_EVENT`
- [x] **Голоса персонажей** — теперь реально выбираются (в меню фича так и описана),
  карта голосов уходит в `dialog-tts`
- [x] Страницы можно удалять, есть «Озвучить всё», закрытие по Escape и клику на фон,
  object URL отзываются при удалении/переозвучке/размонтировании
- [x] Тесты: `mangaVoiceModal.test.tsx` (18), `mangaPages.test.ts` (16), `mangaTranscript.test.ts` (15),
  `mangaAnalyze.test.ts` (19, включая стражи конфига и контракта с `dialog-tts`),
  `audioPlayer.test.tsx` (6) — всего 221 тест
